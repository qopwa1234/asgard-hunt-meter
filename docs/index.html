3. 시세·채팅·아이콘 공유선택 기능
커뮤니티 서버는 비공개로 운영됩니다. 게임 계정 비밀번호는 절대 사용하지 마세요.
INSTALL

3분이면 시작

1. 다운로드

Releases에서 AsgardHuntMeter-*.zip을 받아 압축을 풉니다.

2. 실행

AsgardHuntMeter.exe를 관리자 권한으로 실행 → ▶ 청취 시작.

첫 실행 시 필요한 구성 요소와 아이콘을 자동으로 준비합니다. 인터넷 연결이 필요합니다.

3. 아이콘

자동으로 받아오지 못했다면 🌐 커뮤니티 → 최신 팩 받기 또는 ZIP 가져오기.

요구 사항

  • Windows 10/11 64-bit
  • Npcap (Wireshark 설치 시 포함)
  • 관리자 권한
  • 게임과 같은 PC에서 실행
본 도구는 게임을 조작하지 않는 측정 도구입니다. 게임 이용약관과 계정 보안은 사용자 책임입니다.
