아스가르드 트래커 {{VERSION}}

게임 플레이 정보를 실시간으로 정리해 주는 Windows용 사냥 수익 측정 도구입니다.
자동 사냥, 게임 조작, 메모리 읽기/주입 기능은 없습니다.

[요구 사항]
- Windows 10/11 64-bit
- Npcap (Wireshark 설치 시 기본 포함)
- 관리자 권한
- 첫 실행 시 인터넷 연결 (필요한 구성 요소 준비)

[실행 방법]
1) Npcap이 없으면 https://npcap.com 에서 설치합니다.
2) 이 폴더의 AsgardHuntMeter.exe를 "관리자 권한으로 실행"합니다.
3) 상단 [▶ 청취 시작]을 누르고 게임에 접속해 사냥합니다.
   - 필수 설정은 앱에 내장된 관리 값으로 고정되어 있습니다.

[주요 기능]
- 수익: 골드 / EXP / 명성, 시간당 수익, 최근 5분 페이스, 목표 달성 알림
- 전투: 킬 수, 몹별 킬 통계, 파티원 HP/MP
- 아이템: 획득 목록, 슬롯/스택/충전, 가방 자산 가치, 아이템 시세 환산
- 버프: 남은 시간, 만료 임박 알림, R포션/요리 재고 경고
- 채팅: 채널 필터, 키워드 알림, CSV/TXT 저장, 귓말 모아보기
- 대시보드: 분당 그래프, 세션 기록, HTML 리포트, 그래프 CSV
- PiP: 게임 위에 항상 표시되는 미니 오버레이
- 커뮤니티: 시세 제보/평가, 채팅, 기여도 포인트, 배지/칭호/닉네임 색상 상점
- 아이콘 팩: 앱에서 최신 팩 받기, ZIP 가져오기/내보내기
- 업데이트: 앱 안에서 새 버전 확인 → 다운로드 → 자동 재시작

[데이터 저장 위치]
%APPDATA%\AsgardHuntMeter\
  settings.json / expenses.json / prices.json / homework.json / sessions.json
  icons\ / sessions\

[업데이트]
⚙ 설정 → 🔄 업데이트 → [업데이트 확인]  (v0.3.0부터 지원)
- 시작 시 자동 확인 (끄기 가능)
- 다운로드 후 무결성 검증
- 설정과 기록은 %APPDATA%에 보존됩니다.
- v0.2.1 이하에는 자동 업데이트 기능이 없습니다. 최신 ZIP을 받아 기존 폴더에 덮어쓰세요.

[커뮤니티 서버 (선택)]
- 앱 → 🌐 커뮤니티 → 가입/로그인 (공식 서버 주소는 앱에 내장)
- 게임 계정 정보는 받지 않습니다. 커뮤니티용 닉네임/비밀번호만 사용하세요.
- 서버는 운영자가 비공개로 운영합니다.

[알려진 제한]
- 측정을 시작하기 전에 이미 연결된 세션은 일부 정보를 놓칠 수 있습니다.
- 게임/서버 환경에 따라 일부 아이템과 아이콘 팩이 비어 있을 수 있습니다.
- 커뮤니티 서버가 내려가 있어도 개인 측정 기능은 계속 동작합니다.

[주의]
- 본 도구는 게임을 조작하지 않는 측정 도구입니다. 게임 이용약관과 계정 보안은 사용자 책임입니다.
- 채팅/길드 정보가 저장될 수 있으니 sessions 폴더 관리에 유의하세요.
