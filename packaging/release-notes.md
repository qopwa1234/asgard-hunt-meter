# Asgard Hunt Meter {{VERSION}}

사냥 수익 측정기 **{{VERSION}}** 릴리스입니다.

> **v0.2.1 이하 사용자**: 자동 업데이트 기능이 없습니다. 아래 ZIP을 직접 받아 기존 폴더에 덮어쓰세요. 설정과 기록은 유지됩니다. v0.3.0부터 앱 안에서 자동 업데이트를 지원합니다.

## 하이라이트

- **필수 설정 고정**: 게임 서버와 커뮤니티 주소를 관리 값으로 고정
- **첫 실행 준비**: 필요한 구성 요소와 아이콘을 자동으로 준비 (인터넷 연결 필요)
- **중간 접속 안정성 개선**: 접속이 끊겼다 이어져도 세션 집계 유지
- **원클릭 업데이트**: 앱 안에서 새 버전 확인 → 무결성 검증 → 자동 재시작
- **업데이트 안정성 개선**: 실행 중인 이전 구성 요소를 정리한 뒤 교체
- **기여도 상점**: 시세 제보·평가·아이콘 기여로 포인트를 모아 배지/칭호/닉네임 색상 구매
- **세션 리포트**: 현재 세션과 최근 기록을 HTML로 저장, 그래프 데이터 CSV 내보내기
- **커뮤니티 강화**: 시세/채팅에 배지·칭호·색상 표시, 기여도 랭킹

## 설치

1. `AsgardHuntMeter-{{VERSION}}.zip` 다운로드
2. 원하는 폴더에 압축 해제
3. `AsgardHuntMeter.exe`를 관리자 권한으로 실행
4. ▶ 청취 시작 (필수 설정은 앱에 내장)

요구 사항: Windows 10/11 x64, Npcap(Wireshark 포함), 관리자 권한.

첫 실행 시 필요한 구성 요소를 준비하므로 인터넷 연결이 필요합니다. 이후에는 개인 측정 기능을 오프라인에서도 사용할 수 있습니다.

## 업데이트

기존 사용자는 앱의 **⚙ 설정 → 🔄 업데이트 → 업데이트 확인**으로 바로 설치할 수 있습니다.
수동 업데이트는 새 ZIP을 기존 폴더에 덮어쓰면 됩니다. 설정과 기록은 `%APPDATA%\AsgardHuntMeter`에 보존됩니다.
